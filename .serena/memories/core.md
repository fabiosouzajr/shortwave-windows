# Shortwave Windows port — core

- Unofficial Windows 10/11 x64 port of GNOME Shortwave 5.0 (Rust, GTK4, libadwaita, GStreamer, Diesel/SQLite, radio-browser.info, Google Cast). GPL-3.0-or-later; keep all headers/credits.
- Baseline = Mauna Linux import (`upstream`, push DISABLED) == GNOME 5.0.0 + post-release upstream main changes. GNOME remote `gnome` (push DISABLED). Only push to `origin` (private repo), branch `windows-port`.
- Required features: playback+library, track recording, Chromecast, SMTC media keys. Never drop one without asking the user.
- Port rule: reuse upstream code; isolate Linux-only parts behind `src/platform/{mod,linux,windows}.rs` + cfg-gated deps. Linux build must keep working.
- Reverse-engineering reports (source of truth for coupling + deps): `docs/re/00-09`. Coupling table: `docs/re/08-platform-coupling.md`.
- Source map: `src/main.rs` (init, gettext, gresource), `src/app.rs` (SwApplication singleton, `SwApplication::default()` service locator), `src/audio/` (GStreamer backend, SwPlayer, recording, MPRIS), `src/api/` (radio-browser client, covers), `src/database/`, `src/device/` (mDNS + cast), `src/settings/`, `src/ui/` (GtkBuilder templates in `data/gtk/`).
- `src/config.rs` is generated by Meson from `src/config.rs.in` and gitignored; plain cargo needs it to exist.
- Build/tooling details: `mem:tech_stack`; commands: `mem:suggested_commands`; code style: `mem:conventions`; done-checklist: `mem:task_completion`.
