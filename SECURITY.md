# Security policy

## Supported versions

Only the latest release of the Windows port gets security fixes.

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/fabiosouzajr/shortwave-windows/security/advisories/new).
Don't open a public issue.

You'll get an acknowledgement, and the fix ships in the next `-win.N`
release.

Vulnerabilities in upstream Shortwave code, or in GTK, GStreamer or other
bundled libraries, belong to those projects. Report them there; if the
Windows build is affected, tell us too.
