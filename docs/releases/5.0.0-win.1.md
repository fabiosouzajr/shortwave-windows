The first release of **Shortwave for Windows**, an unofficial Windows 10/11
port of [GNOME Shortwave](https://gitlab.gnome.org/World/Shortwave) 5.0.0.
Listen to over 50,000 internet radio stations from the community-run
[radio-browser.info](https://www.radio-browser.info/) directory, save your
favourites and record what's playing.

This port isn't affiliated with the Shortwave authors or the GNOME project.
Please report problems here, not upstream.

## Download

Both files are for **Windows 10 or 11, 64-bit**.

- **`Shortwave-5.0.0-win.1-windows-x64-setup.exe`**: installer, recommended.
  Adds a Start menu entry and enables toast notifications.
- **`Shortwave-5.0.0-win.1-windows-x64.zip`**: portable. Unzip anywhere and
  run `Shortwave\bin\shortwave.exe`.

Windows SmartScreen may warn that the app is from an unknown publisher,
because the files aren't code-signed. Choose **More info → Run anyway**.

## Highlights

- **Search the way you think**: type a station name or a genre, and narrow
  the results by country, codec and minimum bitrate. The filters work on
  their own too, with nothing typed.
- **One-click favourites**: the heart in the player saves the playing
  station and shows "Station added".
- **Easier to scan**: country flags, bigger station logos (also found on the
  station's own website), and a codec and bitrate meter on every card.
- **Feels at home on Windows**: media keys and the Windows media overlay, a
  tray icon that keeps the radio playing when the window is closed, toast
  notifications, and dark/light mode that follows Windows.
- **Recording** saves tracks to `Music\Shortwave`.
- **Pick your language** in Preferences.

## Known issues

- The Save Track / Don't Record buttons on toast notifications are untested.
- Chromecast devices are found, but casting is untested.
- The per-machine install hasn't been tested; per-user install and uninstall
  work.
- Some new labels appear in English in other languages.
- Saved recordings miss their last few seconds (also the case upstream).
