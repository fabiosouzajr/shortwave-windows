A fix for stations that wouldn't play. **Shortwave for Windows** is an
unofficial Windows 10/11 port of
[GNOME Shortwave](https://gitlab.gnome.org/World/Shortwave) 5.0.0. It isn't
affiliated with the Shortwave authors or the GNOME project; please report
problems here, not upstream.

## Download

Both files are for **Windows 10 or 11, 64-bit**.

- **`Shortwave-5.0.0-win.2-windows-x64-setup.exe`**: installer, recommended.
  Adds a Start menu entry and enables toast notifications.
- **`Shortwave-5.0.0-win.2-windows-x64.zip`**: portable. Unzip anywhere and
  run `Shortwave\bin\shortwave.exe`.

Windows SmartScreen may warn that the app is from an unknown publisher,
because the files aren't code-signed. Choose **More info → Run anyway**.

## What's fixed

- **Stations play on any sound device setting.** If your Windows output
  device was set to a different sample rate than the station's stream (for
  example 96 kHz), every station failed with "Internal data stream error".
  The audio is now converted to your device's rate.

## Known issues

- The newest features (search filters, the heart button, country flags, the
  language picker) pass the automated tests but haven't yet been checked by
  hand in the running app.
- Dark mode following Windows has only been tested in light mode.
- Hardware media keys weren't pressed in testing; the Windows media overlay,
  which uses the same controls, works.
- Windows proxy settings aren't used. Behind a proxy, set the `http_proxy` /
  `https_proxy` environment variables instead.
- The Save Track / Don't Record buttons on toast notifications are untested.
- Chromecast devices are found, but casting is untested.
- The per-machine install hasn't been tested; per-user install and uninstall
  work.
- The new search, filter and heart labels are in English in every language.
- Saved recordings miss their last few seconds (also the case upstream).
